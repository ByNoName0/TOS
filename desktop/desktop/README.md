# TOS Desktop Environment (desktop/desktop)

The TOS desktop shell combines:
- Window Manager: **Openbox** (low latency, ~12 MB RAM footprint)
- Desktop Icons & Wallpaper Renderer: **feh** / **pcmanfm --desktop**
- Compositor: **picom** (clean subtle drop-shadows with zero GPU lag and no heavy blur)
- Right-click desktop menu: Quick access to Terminal, Files, Settings, and Wallpaper switcher
