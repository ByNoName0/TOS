# TOS Panel / Taskbar (desktop/panel)

The TOS panel is powered by `tint2` styled in `#0D1520` with `#1683FF` active window markers.

## Layout (Left to Right)
1. **TOS Logo Button:** Launches the application launcher
2. **Taskbar:** Shows currently active/minimized windows with icon + title
3. **System Tray:**
   - Wi-Fi / Ethernet status indicator
   - Volume slider / Audio indicator (PipeWire / ALSA)
   - Battery level & charging status
   - Digital Clock (HH:MM:SS)
4. **Power Action Button:** Direct access to shutdown/reboot modal
