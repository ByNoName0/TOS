# TOS Settings Application (desktop/settings)

The TOS settings utility provides system configuration:
- **Appearance:** Theme toggle, accent color selector, wallpaper picker
- **Display:** Resolution, scaling, multi-monitor configuration via `xrandr` / `wlr-randr`
- **Network:** Wi-Fi connection manager (`nmtui` / `wpa_gui`), Ethernet IP details
- **Sound:** Output/input volume and device selection (PipeWire)
- **Users:** Add/remove standard user accounts, password changing, sudo privileges
- **System:** Hardware specifications, kernel version, storage audit (`tos-size`), RAM/CPU monitor
- **Power:** Sleep timeouts, power button action, shutdown, restart
