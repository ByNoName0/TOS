# TOS Application Launcher (desktop/launcher)

The TOS application launcher is configured using `rofi` with a custom dark electric-blue theme.

## Features
- Trigger: **Super / Windows Key** (mapped via Openbox `rc.xml` or custom keybinding daemon)
- Full fuzzy-search across `/usr/share/applications`
- Categorized view: System, Internet, Office, Utilities, Settings
- Integrated power controls (Power off, Reboot, Suspend, Logout)
- RAM footprint: < 6 MB resident memory when active
